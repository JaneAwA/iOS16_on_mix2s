# Xiaomi Mi Mix 2S (polaris) hardware parameters
# Source: dtb_36, one of the 64 flattened device trees extracted from the stock boot.img
#         model = "Xiaomi Technologies, Inc. Polaris MP v2.1"  <- retail Mi Mix 2S
# Purpose: these values are written into the AppleDeviceTree by tools/mkadt.py, and into
#          the shim's framebuffer constants.
# Tool:    ci/decode_dtb.py --boot boot.img --outdir dtb_out --match polaris
#
# Bottom line: Mix 2S and SWEET (Snapdragon 732G) share nearly identical GIC / timer / memory
#              layout. The only values that must change are the framebuffer base, panel
#              dimensions, and UFS window size.

[Interrupts / GICv3]           -- identical to SWEET, no change required
GICD           0x17a00000  size 0x10000
GICR           0x17a60000  size 0x100000
virtual timer PPI  INTID 19               (QTI numbering convention phys/virt/hyp = 2/3/0)
security state  dual security; Group0 owned by TZ, remaining Group1 NS (IRQ)
DTB evidence    interrupt-controller@17a00000 reg <0x17a00000 0x10000 0x17a60000 0x100000>

[Storage / UFS host controller]
UFSHC          0x1d84000   size 0x2500        (SWEET mkadt writes 0x3000; measured 0x2500;
                                                driver only touches the register window,
                                                both values work)

[Display / framebuffer]        -- must change
                 SWEET              POLARIS (Mix 2S)
cont splash/FB   0x9c000000          0x9d400000      <- reserved-memory/cont_splash_region
FB length         0x1700000           0x2400000       (36 MB)
physical res      1080x2400           1080x2160       (width=0x438 height=0x870)
stride            1080*4              1080*4
IOMFB canvas      1125x2436           1080x2160
panel             -                   S6E3HA3 AMOLED, 60 Hz (framerate=0x3c)

[Memory]
DDR base         0x80000000
reserved range   0x85700000 .. 0x9f800000     (cont_splash ends at 0x9f800000)
PHYS_BASE        0xb0000000      (inherited from SWEET, above all carve-outs; verified)
MEM_SIZE         0x4d000000
highmem (device) 0x100000000 / 0xfcc0000

[CPU topology]  SDM845 Kryo 385 big.LITTLE
8 cores: cluster0 = Cortex-A75 @ 2.8 GHz (core 0-3), cluster1 = Cortex-A55 @ 1.8 GHz (core 4-7)
DTB reg = 0x0,0x100,...,0x700  flat linear MPIDR (Aff1 = core)
current policy: inherit SWEET's "flat 8-core single cluster" (MAX_CPU_CLUSTERS=1, ADT all
               cluster-id=0); move to dual cluster once the ADT can describe real big.LITTLE.
no PAC pointer authentication -> kernel must be pure arm64, not arm64e.

[Other]
UART / console   qup_uart@0xa84000   (aliases: serial0)
touch             synaptics,dsx-i2c-force   (not Goodix)
PMIC              PM8998 + PMI8998 + PM8005
GPU               Adreno 630
                 register docs: mesa/src/freedreno/registers/adreno/a6xx*.xml
